# Changelog

## 1.0.0-beta.4（未发布）

仓库审阅后的整理版本。用户可见的行为变化很少；重点是安全、域层正确性和代码卫生。

### 安全

- 生产页面不再注入任何第三方脚本；页面只加载同源资源，nginx 增加 CSP、HSTS、`X-Frame-Options` 等响应头。
- 移除平台身份网关（请求头触发的会话生成、从本机端口拉取 JWKS）、OAuth 中介、bearer/popup 登录路径和 `VITE_AUTH_ENABLED` 开关。账号只剩本机邮箱密码，是否可用完全由运行时探测决定。
- 删除仓库内的明文 OAuth client secret。
- 开发服务器只监听 127.0.0.1。

### 域层修复

- 其他标签页激活恢复副本后，本页会自动脱离 `RECOVERY_REQUIRED` 状态，可以继续编辑。
- 提交进行中执行「放弃草稿」不再清空正在写入的附件字节。
- 园子（旧社区）引用统一由 `gardens.ts` 解析；损坏的园子数据只会推迟附件清理，不再阻塞知识保存，也不会丢弃待写入的附件。
- 「重置学习状态」写入历史事件，完整历史仍可回放到当前状态；首次完成时间保留。
- 校验：去掉节点上错误的 `historyCompleteSince` 检查和永远不会触发的复盘重复检查。
- 备份：归档内 JSON 损坏返回数据错误而不是原始 `SyntaxError`；恢复时的园子引用重映射能容忍缺字段。
- 公式解析：`$` 后紧跟数字不再视为公式边界（`$5,$6`）。
- 周回顾的 P0 清单按分区顺序而不是分区 ID 排序；创建树不再多写一次改名命令。

### 界面

- 中英文文案补全：导入 / 恢复 / 恢复页、引导、下载页、账号面板、公式编辑器、周回顾、实践日志、结构菜单全部走 i18n；存储错误说明提供英文版本。
- `knowledge-app.tsx` 拆分为 `week-page.tsx`、`log-page.tsx`、`tree-switcher.tsx`；修复变量遮蔽、重复渲染的底栏和未清理的提示计时器。
- 导入 / 恢复确认失败时按钮不再永久禁用；「放弃草稿」改用应用内确认框。
- 无障碍：标签页、底栏、筛选按钮补充 ARIA 状态；可展开的日志卡片和附件投放区改为真正的按钮；状态标记按钮有可读标签。
- 错误页与产品视觉一致；PWA 清单和图标改为 Leo Tree 自己的。

### 仓库卫生

- 移除未使用的依赖（约 40 个 UI 库），`npm ci` 重新可用。
- 移除废弃 CSS（旧社区 / 园子样式）与死代码（未调用的附件 / 进度 / 工厂函数）。
- 文档与代码对齐：README、架构、测试说明、部署文档重写，历史报告移入 `docs/history/`。
- `tsconfig.json` 去掉已废弃的 `baseUrl`。
- 71 MB 的历史验收产物 `release-evidence/` 从整个 git 历史中清除（`git filter-repo`，所有提交哈希随之改变）并加入 `.gitignore`，原件由维护者离线保存；`activate.sh` 每次激活都重新生成 nginx 站点。
